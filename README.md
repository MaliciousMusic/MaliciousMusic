### 🧭 Engineering philosophy

- **Proposer ≠ judge** — models propose; Lean 4, SAT/DRAT or interval arithmetic decide.
- **Measure, don't assert** — seeded, paired evaluation; every number traces back to an artifact.
- **Refutations are first-class** — killed ideas are logged so no dead end is walked twice.
- **Offline & private by design** — local, air-gapped inference when the data deserves it.
